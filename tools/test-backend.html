Front ↔ Back

Cette page ne fait rien d'autre que parler à ta base de données en HTTP, et te montrer chaque requête telle qu'elle part et telle qu'elle revient. Une fois que les 3 voyants sont verts, la partie difficile est derrière toi.

Aucune donnée ne sort d'ici sauf vers ton projet 100 % statique, hébergeable sur GitHub Pages

1 · Connexion

Tes deux clés

non configuré

Dans Supabase : Settings → API Keys. Récupère le Project URL et la clé anon public. Elles sont enregistrées uniquement dans ce navigateur (localStorage).

2 · Écriture

Envoyer un score

Un POST vers /rest/v1/scores avec un objet JSON dans le corps. C'est littéralement tout ce qu'est « écrire en base » depuis le front.

3 · Lecture

Relire & agréger

Un GET avec des filtres directement dans l'URL. Le classement ci-dessous est calculé en JS, mais Supabase sait aussi le faire côté serveur — c'est tout l'intérêt d'avoir du vrai SQL derrière.

Aucune ligne. Si tu viens d'en écrire une, c'est très probablement une policy RLS manquante (revois l'étape 2 du tuto).
